# Ai.Tasks — kickoff-брифы для агентов

Один файл — одна задача. Порядок работы — `<Knowledge>\process\agent-workflow.md` § 2, раздел «Редактор» — там же § 3.

## Шаблон

```text
# YYYY-MM-DD — короткое название
Статус: planned | in progress | done | blocked
Исполнитель: координатор | unity-worker | человек

## Goal
## Constraints
## Paths

## Редактор
Что в Unity: объекты и префабы, компоненты и поля Inspector, теги и слои,
как выглядит в Scene view и в Game view, что делает Editor-скрипт, что руками,
неочевидные места.

| # | Шаг (что, где) | Ожидаемый результат | Статус |
|---|---|---|---|
| 1 | | | не сделано / сделано (со слов) / проверено по файлу |

## DoD
## Don't-touch

## Итог
```

## Правила

- Имя файла: `YYYY-MM-DD-short-kebab.md`, при появлении нового статуса файл обновляем, а не дублируем.
- Бриф пишется до старта работы, итог дописывается после.
- Шаг в редакторе отмечается «проверено по файлу» только после чтения YAML/диффа или проверки через Unity CLI.
- Завершённые задачи, которые привели к фиксу, дублируются в `Ai.Issues/` (bugs или features); настройки редактора — в `Ai.Architecture/editor-setup.md`.
- Задачи по Enemy/Aggro, которые ведёт другой агент, сюда не ставим без его ведома.
